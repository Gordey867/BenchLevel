# BenchLevel

Індикатор відхилення від каліброваної площини на Nucleo-C031C6. Гордєєв Ілля Євгенович, ІО-35.

MPU6050 через I2C вимірює гравітацію; потенціометр задає допуск 0,5..5°, кнопка CAL калібрує еталон. LED показує UNCAL, CAL, LEVEL, TILT та ERROR. ЛР3 перевіряє допуски X/Y окремо, приймає UART-команди та передбачає збереження стабільного результату. HAL STM32C0 збережено.

```sh
make build
make test
make coverage
```

Потрібні Docker, make і Python 3. Відкрийте папку у VS Code, F1 → Wokwi: Start Simulator. Якщо симулятор лише відкрився, натисніть зелену кнопку Start. UART 115200 8N1 відкривається всередині Wokwi. `make flash` і `make monitor` показують команду запуску симуляції.

Для калібрування встановіть Acceleration X=0, Y=0, Z=1 g, натисніть CAL або надішліть `CAL` і тримайте датчик нерухомо близько секунди. Зміна Acceleration X=0,6, Z=0,8 g дає близько 36,87° і TILT після фільтра та витримки. Поля Rotation задають кутову швидкість. Потенціометр Home/End задає ADC 0/4095. Утримання CAL 2 с або `PROBE` викликає запит до відсутнього 0x69, ERROR і повторний init через 1 с. Після відновлення потрібне нове калібрування або явний `LOAD` зі свіжою перевіркою стабілізації.

`LIMIT 1000 2500` задає окремі межі у mdeg, `POT` повертає потенціометр. `STATUS`, `STATS`, `RESET` керують діагностикою. `SAVE` після стабілізації запускає збереження, `EXPORT` показує стан носія; ACK не підтверджує успішний запис. У Wokwi readback erase виявив помилку, див. [результати ЛР3](docs/lab3-results-20261101.md). Діагностична `PERIOD 2` змінює частоту запитів для пошуку межі, штатна `PERIOD 50`. Знаки x/y задають відхилення, корекція має протилежний знак; yaw не вимірюється.

Локальні теги `lab1` і `lab2` фіксують завершені етапи. Для ЛР3 пройдено 32 host-тести та ASan/UBSan. S1, неперервний S2, дві серії S3, старт і межу UART досліджено у Wokwi; результати й обмеження наведено в документації. Host-година з керованим часом не є годиною роботи MCU. Реальні записи ЛР2 у docs/captures і docs/screenshots збережено; вони не підтверджують нову версію. Фізичну плату не випробувано.

У перевіреній VM Ubuntu 24.04 доступна пряма збірка `make -C firmware all` та `make -C tests test CC=gcc-13`. Для coverage потрібні узгоджені GCC/gcov; перевірено версії 13.3.
