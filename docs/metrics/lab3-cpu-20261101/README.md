# Профіль виконуваних задач BenchLevel

Дослід у Wokwi використовує окремий діагностичний ELF `39d8f476aba2ebc2fbcbf388c8fe616b82eec02c386b58950e62c126f0f1f7b9`, source `cpu-selected-v1`. Заморожений S1–S3 ELF — `9bd2a08470af183e18386b2763c994dad2050f76f84c59adb1e84287c1f48b09`; до нього ці числа не переносяться. [Діагностичний стенд і джерело змін](../../../diagnostics/cpu-profile/README.md).

У неперервному VCD-вікні 20–30 с після CAL система перебувала в LEVEL; STATUS надсилали приблизно раз на 2 с, без SAVE та STATS. D7 позначав виклик контрольної задачі, активні гілки ADC і команд, підготовку та запуск UART-відповідей. Порожній міжзадачний spin не позначений, а асинхронна передача після виходу з функції не вважається виконанням задачі. D0/D1/D5 — відповідно USART, SysTick та I²C ISR; D2/D6 — UART TX/RX, D3/D4 — I²C SCL/SDA. Старі записи мають інше відображення каналів.

| Метрика | Значення |
|---|---:|
| D7, включно з ISR | 9,634579% |
| Позначені foreground-задачі без перекриття з ISR | 9,504080% |
| Об'єднання позначених ISR | 1,446572% |
| Об'єднання foreground та ISR | 10,950651% |
| Кількість D7 / SysTick імпульсів | 10 220 / 10 000 |

Два незалежні алгоритми інтегрування переходів VCD дали однакові 950 407 950 нс foreground без ISR та 1 095 065 125 нс для об'єднання. 32 пари калібрувальних записів GPIO на старті дали імпульси по 250 нс, але це не повна оцінка накладних витрат; автоматичного віднімання немає. Діагностичні маркери і код можуть впливати на планування. Не всі допоміжні гілки й переривання охоплені, тому результат не є повною завантаженістю ядра або гарантією нижньої межі. Фізичну плату не вимірювали.

Матеріали: [VCD gzip](profile.vcd.gz), [UART](uart.raw), [стимули](stimuli.json), [перший інтеграл](analysis.json), [незалежний інтеграл](independent-integral.json), [опис збору](collector.json). SHA-256 розпакованого VCD: `13f8a04831e49292fcb5ba8ff6877cb29867c73667dba2a4630c731ea9e608ca`; UART: `4cc336b17a7bf00cbb715e7528a938a3faa99d56201029086438a5bcbfe104a8`. Відтворюється аналіз наявного запису:

```sh
gzip -dc docs/metrics/lab3-cpu-20261101/profile.vcd.gz > /tmp/benchlevel-cpu.vcd
python3 diagnostics/cpu-profile/analyze-profile.py /tmp/benchlevel-cpu.vcd --start-ns 20000000000 --end-ns 30000000000 --output /tmp/benchlevel-cpu-analysis.json
python3 diagnostics/cpu-profile/verify-integral.py /tmp/benchlevel-cpu.vcd
```
