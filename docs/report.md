# Лабораторна робота №1: BenchLevel

Гордєєв Ілля Євгенович, ІО-35. Середовище: Ubuntu 24.04, Docker, STM32 HAL, Wokwi.

Мета: перевірити конвеєр збірки й початковий запуск Nucleo-C031C6 та визначити функції вирівнювання платформи. Повний звіт із титулом: [PDF](lab1-report.pdf).

Реально виконано дві чисті збірки в Linux-контейнері. ELF 396436 байтів, HEX 42962, BIN 15248 збігаються побайтно. Хеші й фактичний час наведені у [reproducibility.json](verification/lab1/reproducibility.json). Flash text+data 15248 байтів; bss 2224. Віддалений CI не запускався.

Wokwi виконав прошивку, UART показав tick 1, 2, 3 та probe 0x68 status=0. Реальний [знімок](screenshots/lab1/wokwi-uart.png), [VCD](captures/lab1/i2c-probe.vcd), [SR](captures/lab1/i2c-probe.sr) та [декодований I²C](captures/lab1/i2c-decoded.txt) збережено. SR отримано з downsample=1000, 1 МГц; первинний VCD не редагувався. Видимий UART-лог є витягом із viewport, а не повним потоком.

## Рішення та проблеми

| Симптом | Причина | Рішення й етап |
|---|---|---|
| Немає ADC-модулів | Мінімальний шаблон UART/LED | Додано офіційний HAL v1.0.1, 34895fe |
| Схема лише з платою | Немає периферії теми | MPU6050, ADC-потенціометр, CAL, аналізатор, 34895fe |
| Ubuntu 22.04 у Dockerfile | Стара база шаблону | Ubuntu 24.04, реальна збірка, 34895fe |
| Немає доказу відтворюваності | Відсутні контрольні результати | Дві clean/build і SHA-256, eda79d2 |
| VCD імпортується як мільярди відліків | Крок Wokwi 1 нс | Downsample для SR зі збереженням оригіналу, eda79d2 |

[PRD](PRD.md) містить 13 вимог і план їх перевірки. [Дослідження](hardware-components.md) розрізняє datasheet МК, RM, UM плати й документацію сенсора. I²C/ADC/GPIO відповідають формі B. Камера, SPI та DCMI у темі не використовуються.

Результат ЛР1 підтверджує збірку, UART/LED та ACK на I²C. Він не підтверджує ще не реалізовані функції калібрування та вимірювання кута. Електричні характеристики й точність фізичного приладу не виміряні.
