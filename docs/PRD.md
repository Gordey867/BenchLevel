# BenchLevel: вимоги до продукту

## Ідея

BenchLevel допомагає виставити невелику нерухому платформу відносно вибраної початкової площини. Користувач встановлює платформу, натискає CAL і отримує індикацію відхилення. Це навчальний індикатор, а не сертифікований рівень. Автоматичного приводу немає.

Точність залежить від кріплення IMU, температури, вібрації та калібрування. Показаний допуск є параметром алгоритму. Його не можна вважати метрологічно підтвердженою похибкою.

## Функціональні вимоги

| ID | Вимога | Перевірка |
|---|---|---|
| FR-01 | Після старту система видає в UART результат ініціалізації та WHO_AM_I MPU6050. | ID 0x68; неправильний ID переводить у ERROR. |
| FR-02 | Кнопка CAL задає початкову площину за 20 послідовними придатними відліками з періодом 50 мс. | До завершення CAL; після завершення LEVEL. |
| FR-03 | До калібрування система має стан UNCAL та не підтверджує вирівнювання. | Старт без натискання CAL. |
| FR-04 | Система обчислює кут між поточним і каліброваним векторами прискорення. | Вектори 0°, 30°, 90° у host-тестах. |
| FR-05 | Потенціометр змінює допуск від 0,5° до 5° за кодом ADC 0..4095. | Кінці шкали й середина; UART tol_mdeg. |
| FR-06 | Відліки обробляються кожні 50 мс; ADC, кнопка та I²C працюють разом. | Marker GPIO та одночасні події. |
| FR-07 | Дребезг кнопки коротший за 30 мс не починає нове калібрування. | Bounce та утримання. |
| FR-08 | Перехід LEVEL/TILT потребує 300 мс сталого кандидата; повернення LEVEL має гістерезис 0,2°. | Значення навколо порога, зміна допуску. |
| FR-09 | LED світиться у LEVEL; блимає у TILT, CAL та ERROR з різними періодами; UNCAL погашений. | UART state зіставляється з PA5. |
| FR-10 | Помилка шини або відсутність придатного відліку понад 250 мс переводить систему у ERROR. | NACK, timeout, stale data, переповнення часу. |
| FR-11 | Система повторює ініціалізацію після помилки з інтервалом 1 с, без нескінченного очікування. | Відновлення пристрою та backoff. |
| FR-12 | Модуль прискорення поза 0,85..1,15 g відкидається. Під час CAL розкид понад 0,02 g скидає накопичення. | Нульовий, насичений і рухомий вектори. |
| FR-13 | UART підтримує `i` для ідентифікації та `n` для звернення до незайнятої адреси 0x69. | Нормальний запис і адресний NACK. |

## Компоненти й альтернативи

MPU6050 вимірює вектор тяжіння через I²C для FR-01, FR-02, FR-04, FR-12. Гіроскоп потрібен для діагностики, інтегрування швидкості не застосовується. MPU6050 обрано через модель Wokwi та відкриту карту регістрів. LIS3DH також вимірює прискорення, але заміна не потрібна для теми. Механічний бульбашковий рівень не забезпечує UART і програмне калібрування.

Потенціометр 10 кОм через ADC задає FR-05. Дві кнопки для зміни допуску потребували б додаткових GPIO. Кнопка CAL через GPIO задає FR-02, FR-07; постійне автоматичне калібрування приховало б відхилення платформи.

## План перевірок і межі

ЛР1 перевіряє конвеєр, UART, LED та доступність I²C. ЛР2 реалізує всі FR. Host-тести перевіряють драйвер через mock шини, прикладну логіку через контрольований час та захоплені байти. Wokwi перевіряє спільну роботу HAL-прошивки та схеми. VCD перевіряє цифрові сигнали незалежно від UART. ADC не має цифрової транзакції: завершення вимірювання позначається службовим GPIO.

На реальній платі потрібні вимірювання живлення, фронтів I²C, стабільності кріплення та порівняння кута з еталоном. Симулятор цього не замінює. Камера, SPI-flash, PWM і DCMI у продукті не використовуються.
