# Базова лінія BenchLevel для ЛР4

ЛР4 не реалізовано. Порівняння ведеться з кандидатом source `156cce9152e16852`, ELF SHA-256 `9bd2a08470af183e18386b2763c994dad2050f76f84c59adb1e84287c1f48b09`; спосіб побітового відтворення наведено у [результатах ЛР3](lab3-results-20261101.md). Стенд: Nucleo-C031C6, Ubuntu 24.04, Docker, STM32 HAL, Wokwi. Таймер виміряної версії — HAL tick 1 мс; окремі GPIO і VCD дають незалежний часовий масштаб для подій. Для цього ELF CPU load і короткий WCET не визначені; GPIO-профіль нижче належить окремому образу.

| Метрика | ЛР3 |
|---|---|
| S1 / S2 MCU | 185 000 / 3 610 000 мс; S2 неперервний |
| S2 SAMPLE min/avg/max | 45 / 50 / 55 мс, n=72 260; skipped=0, max late=1 мс |
| S2 dispatch / команди | loop_skip=79 927, command_late=13 |
| S3: дві окремі серії по 25 | min/avg/max 212,600/433,035/650,501 мс і 100,758/313,721/527,514 мс |
| Flash / RAM linker | 27 652 / 28 672 B; 7 824 / 12 288 B |
| Stack watermark / heap | 668 B спостережено / 0 B |
| CPU, окремий діагностичний образ | LEVEL, 10 с VCD: позначені foreground-задачі 9,504% без позначених ISR; ISR union 1,447%; разом 10,951% |
| Збереження, power loss | readback erase не пройдено; фізична втрата живлення не випробувана |
| Boundary UART | 25/с: 250 пар, max 13,304 мс; 50/с: 259 втрачених байтів, 446 command_late |
| Старт, штатна модель | перший повний UART seq=1 через 133,351 мс VCD |
| Старт, модель NACK→ACK | ACK 2011,504 мс, перший повний рядок seq=1 2137,445 мс VCD |
| Фізична плата | не випробувано |

S3 вимірює реакцію під час передачі STATS. Ціль 20 мс у PRD застосовна поза STATS та flash; ці числа не встановлюють порушення тієї умови. Сирі UART і VCD збережені поза репозиторієм; посилання, hash і межі інтерпретації наведені в результатах. Для ЛР4 використати той самий стенд і окремо повторити порівнювані сценарії, зокрема вихід на межу та фізичну цілісність запису. Гіпотези і ціна механізмів ОС наведені в [limitations.md](limitations.md).

CPU-оцінку отримано іншим ELF `39d8f476aba2ebc2fbcbf388c8fe616b82eec02c386b58950e62c126f0f1f7b9`, source `cpu-selected-v1`; її не переносити на S2 з ELF `9bd2...`. Під час LEVEL і STATUS раз на 2 с D7 охоплював `controller_step`, активні ADC/командні гілки і формування/запуск відповіді; D0/D1/D5 — USART/SysTick/I²C ISR. Перекриття ISR з D7 виключено з foreground; busy-spin і невідзначений допоміжний код не рахувалися, тому це не повна зайнятість ядра. За 10 с VCD 32 boot-калібрувальні пари GPIO мали ширину по 250 нс; повні накладні витрати та вплив зміненого образу не визначені. Два незалежні інтеграли VCD збіглися.
