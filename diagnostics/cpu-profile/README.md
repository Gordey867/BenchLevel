# Діагностичний профіль CPU

Цей стенд призначений лише для короткого окремого профілю в Wokwi; він не замінює основну прошивку. [ELF](run-profile/firmware.elf) SHA-256 `39d8f476aba2ebc2fbcbf388c8fe616b82eec02c386b58950e62c126f0f1f7b9`, [HEX](run-profile/firmware.hex) SHA-256 `4f899815d7948fe8cc1fe7c263645dea8fc0a502e1d502d8bc023db40350c033`, `VERSION source=cpu-selected-v1`. Основний заморожений ELF S1–S3 має SHA-256 `9bd2a08470af183e18386b2763c994dad2050f76f84c59adb1e84287c1f48b09` і source `156cce9152e16852`. Вимірювання нового образу не підтверджують завантаження CPU в одногодинному S2.

[Instrumentation patch](instrumentation.patch) описує відмінності діагностичних `platform.c` та `stm32c0xx_it.c` від основного дерева. Застосовувати його лише в окремій копії командою `git apply --unidiff-zero diagnostics/cpu-profile/instrumentation.patch`: патч не має контекстних рядків. Заголовок ідентифікатора діагностичного build містить `BENCH_GIT_ID` `c9ee9ab-diagnostic` і `BENCH_SOURCE_ID` `cpu-selected-v1`; звичайна збірка генерує власні значення. Різниця опцій, інструментів або рядків build ID може змінити ELF. Перевіряти hash перед порівнянням і зберігати первинний виміряний образ. Образи, конфігурація стенда та схема знаходяться в [run-profile](run-profile/).

[Дані, точні результати і межі методу](../../docs/metrics/lab3-cpu-20261101/README.md). D7 позначає вибрані реально виконувані ділянки задач, D0/D1/D5 — USART/SysTick/I²C ISR; перетини усуваються в аналізі. ISR entry/exit і непозначені ділянки не охоплені повністю; зайнятість очікування у міжзадачному busy-spin не входить. Калібрувальні GPIO-імпульси не віднімаються автоматично. Результат є оцінкою у конкретному короткому досліді Wokwi, не повною завантаженістю ядра чи фізичної плати.

[Колектор](collect-profile.py) перевіряє хеш діагностичного ELF і VERSION, надсилає CAL та STATUS у LEVEL, зберігає UART і стимули; збирання VCD контролюється окремо. Він використовує RFC2217 порт 43215 і потребує `pyserial==3.5`. [Аналізатор](analyze-profile.py) обчислює об'єднання інтервалів GPIO; [незалежна перевірка](verify-integral.py) інтегрує сигнали іншим проходом і призначена для вікна 20–30 с поточного запису.
